# Kunhan Gao

Personal homepage: <https://kunhan-g.github.io/>

This repository is the source of that site. It is a Jekyll site that uses the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme.

- `index.md` is the page text.
- `_config.yml` holds the name, affiliation, location, and email shown in the sidebar.
